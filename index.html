🛏️ 료칸에서 1박 한다면

온천 당일치기 대신 온천지에서 하룻밤 자는 안입니다. 저녁 가이세키 + 아침 일식 한상(1박 2식)이 기본 구성이고, 객실 노천탕이나 전세탕이 있는 곳도 많습니다.

⚠️ 료칸은 객실당이 아니라 「1인당」 요금제입니다. 호텔처럼 방 하나에 여러 명 넣는 식으로 계산하면 견적이 완전히 어긋납니다. 예약 사이트에서 반드시 실제 인원(8명)으로 검색해야 맞는 금액이 나옵니다.

💡 8명이면 중급 1박이 현실적입니다. 1인 25만원으로 잡아도 8명이면 200만원이라 회비·분담 얘기가 같이 나와야 합니다. 하카타 호텔 1박과 비교하면 1인당 15~20만원이 더 드는 셈이니, 예산 투표와 같이 보고 결정합시다.
금액은 원화 환산 참고값이고 시즌·요일에 따라 크게 흔들립니다. 날짜 정해지면 8명 기준으로 실제 견적을 뽑아 공유하겠습니다.

👥 참여 회원

⚙️ 실시간 동기화 설정 (관리자용)

📖 Firebase 연결 방법 (설정 완료 — 나중에 다시 만들 때 참고용)

현재 tsuri-trip-2026 Firebase 프로젝트(싱가포르 리전, 무료 Spark 요금제)에 연결되어 있습니다. 규칙은 trip2026 경로만 열려 있고 나머지는 전부 차단되어 있습니다.

  1. console.firebase.google.com → 프로젝트 만들기 (애널리틱스는 사용 안 함)
  2. 빌드 → Realtime Database → 데이터베이스 만들기 · 위치 asia-southeast1(싱가포르) · 잠금 모드로 시작 (테스트 모드는 30일 뒤 만료되므로 피할 것)
  3. 생성 후 나오는 주소 복사
  4. 규칙 탭을 아래로 바꾸고 게시 
    {
  "rules": {
    ".read": false,
    ".write": false,
    "trip2026": { ".read": true, ".write": true }
  }
}
  5. 주소를 index.html 상단 FIREBASE_DB_URL에 넣고 커밋
