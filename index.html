🦑 이번 원정 개요

9월 주말이 이미 다 차서 10월로 넘긴 서해 워킹 쭈꾸미 원정입니다. 배 타는 선상 출조 대신 방파제·갯바위에서 걸어 다니며 던지고, 밤에는 차박 또는 텐트로 자면서 고기 굽고 잡은 거 먹자는 게 원안입니다. 해상좌대(방갈로 제공) 안도 후보에 올라와 있습니다.

💬 단톡방 논의 요약

지금까지 나온 의견을 사람별로 정리했습니다. 빠진 게 있으면 토론 탭에 남겨주세요.

김기태
9월 주말은 이미 꽉 참 → 10월 1·2·3일 가능. 무창포는 너무 멀다, 다른 데 알아보자. 좌대(무지개좌대)도 괜찮을 듯 — 고기 사가서 굽고, 잡은 것도 먹고.
박중산
일정 올려봐야 안다 → 10월로 진행. 무창포·석모도 알아봤고, 워킹이나 차에서 자는 장소를 더 찾아보자. 회비 건은 공지 후 결정하자.
윤유병
10월 1·2·3일 가능. 2박 하고 토요일 귀가. 굳이 좌대 말고 텐트나 차에서 자면서 워킹 쭈꾸미 하자는 게 원안.
최근호
태안 쪽이 편하다, 안면도 많이 간다.
최진원
10월 2일 출발 가능. 회비가 세 군데 중 여기가 제일 비싸니 월 5만원 정도로 인하 제안 (다수결로 결정하자).

📅 2박 3일 표준 일정 (초안)

"2박 하고 토요일 올라온다"는 안을 기준으로 짠 표준 타임라인입니다. 최종 날짜·장소가 확정되면 시간만 바꿔 쓰면 됩니다.

  • DAY 1 · 목(또는 금) 오후
    퇴근 후 출발 → 카풀 집결 → 현지 도착
    집결지에서 차량별 인원·짐 배분 · 마트에서 고기/술/얼음 구매 · 도착 후 차박·텐트 자리 잡기
  • DAY 1 · 밤
    첫 물때 워킹 낚시 + 바베큐
    밀물·썰물 시간에 맞춰 방파제 워킹 · 잡은 건 바로 손질 · 고기 굽고 한잔 (음주 후에는 물가 접근 금지)
  • DAY 2 · 새벽~오전
    해 뜰 무렵 본 게임
    쭈꾸미는 이른 아침·해질녘이 승부처 · 조과 안 나오면 근처 포인트로 이동
  • DAY 2 · 낮
    휴식 / 자유시간
    낮잠·해장·근처 항구 구경 · 낚시 쉬는 분들은 시장·카페 자유 일정
  • DAY 2 · 저녁~밤
    2차 출조 + 뒤풀이
    잡은 쭈꾸미 라면·볶음 · 남은 고기 정리 · 다음 원정 이야기
  • DAY 3 · 토요일 오전
    아침 조과 마무리 → 철수 → 귀가
    쓰레기 전량 수거 · 장비 정리 · 점심 전후 출발해 오후 서울 도착

🌊 물때 · 안전 체크

  • 물때가 전부입니다. 출발일이 확정되면 그 날짜의 만조·간조 시간을 확인해서 낚시 시간을 잡습니다. (국립해양조사원 조석예보)
  • 구명조끼는 방파제·좌대 모두 필수입니다. 밤에는 헤드랜턴 + 여분 건전지 필수.
  • 기상·풍랑특보는 출발 전날 반드시 재확인. 특보가 뜨면 일정 순연을 원칙으로 합니다.
  • 쓰레기는 전량 수거. 다음에 또 가려면 이게 제일 중요합니다.

🗳️ 투표 안내

참가 여부만 단일 선택이고, 나머지는 전부 복수 선택입니다. 가능한 날짜·가고 싶은 장소를 여러 개 고르면 겹치는 날로 자동 집계됩니다. 다시 누르면 취소됩니다.

📖 Firebase 연결 방법 (약 10분, 무료)

Firebase는 주소·키가 공개되는 것을 전제로 만들어진 서비스라, 이 페이지에 주소를 그대로 적어도 안전합니다. 접근 제어는 Firebase 쪽 "규칙"으로 합니다. (이전 GitHub 토큰 방식이 계속 만료되던 문제가 해결됩니다.)

  1. console.firebase.google.com 접속 → 구글 계정 로그인 → 프로젝트 만들기 (이름은 아무거나, 예: tsuri-trip-2026). Google 애널리틱스는 사용 안 함으로 두면 더 빠릅니다.
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기. 위치는 asia-southeast1 (싱가포르) 선택. 보안 규칙은 테스트 모드로 시작.
  3. 만들어지면 화면 위에 나오는 주소를 복사합니다.
    https://○○○-default-rtdb.asia-southeast1.firebasedatabase.app
  4. 규칙 탭으로 가서 아래 내용으로 바꾸고 게시. (이 페이지가 쓰는 trip2026 칸만 열고 나머지는 잠급니다) 
    {
  "rules": {
    ".read": false,
    ".write": false,
    "trip2026": { ".read": true, ".write": true }
  }
}
  5. 복사한 주소를 index.html 상단 const FIREBASE_DB_URL = ''; 의 따옴표 안에 붙여넣고 저장 → GitHub에 커밋하면 끝. 1~2분 뒤 전 회원 화면이 실시간으로 연결됩니다.
💡 3단계까지만 하고 주소만 알려주셔도 나머지(4·5단계)는 대신 넣어드릴 수 있습니다.
⚠️ 위 규칙은 주소를 아는 사람은 누구나 읽고 쓸 수 있는 설정입니다. 이 페이지는 검색엔진에 노출되지 않고 주소도 단톡방에만 공유하므로 이 정도면 충분하지만, 더 잠그고 싶으면 알려주세요.
