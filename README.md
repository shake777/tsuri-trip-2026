투표는 **보기 번호**로 저장됩니다. `ny_when`의 1월 보기(기존 0~3번)는 화면에서 뺐지만, 2~3월 보기(기존 4~9번)의 번호를 `keys: [4, 5, 6, 7, 8, 9]`로 고정해 이미 들어온 표가 옮겨가지 않게 했습니다. 1월 표는 Firebase에 그대로 남아 있습니다. 보기 순서를 바꾸거나 번호를 다시 매기지 마세요.
