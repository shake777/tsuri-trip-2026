# 🍻 송년모임 & ✈️ 신년회 — 회원 전용 계획 페이지

두 안건을 **투표**로 정하고 결과가 전 회원에게 실시간 공유되는 페이지입니다.

👉 https://shake777.github.io/tsuri-trip-2026/

| 안건 | 내용 |
|---|---|
| 🍻 **송년모임** | 11월 중 **금~토 1박2일** · 김포·강화·석모도 권역 · 저녁(고기·술) + 낚시 가능한 펜션 |
| ✈️ **2027 신년회** | **후쿠오카 3박** · **부산 1박은 필요한 사람만**(수요일 선출발) |

> 부산 1박 하는 사람은 수요일 출발 **4박5일**, 패스하는 사람은 목요일 출발 **3박4일**.
> 목~일 후쿠오카 3박은 전원 동일합니다.

## 사용법

1. 위 링크 접속 → 본인 이름 클릭 → 비밀번호 6자리 입력
2. **🍻 송년모임** / **✈️ 신년회** 탭에서 항목 클릭 (다시 누르면 취소)
3. 끝. 저장 버튼 없이 자동으로 저장되고 다른 회원 화면에 15초 안에 반영됩니다

## 투표 항목

**🍻 송년모임** — 참가 여부 · 날짜 · 장소(6곳) · 하고 싶은 것 · 1인 예산
**✈️ 신년회** — 참가 여부 · 주간(목~일) · 가는 편·오는 편 · 수요일 전날 일정 · 온천 · 숙박 구성 · 그 외 활동 · 1인 예산

규칙: **참가 여부만 단일 선택**, 나머지는 복수 선택. 동률이면 재투표 안내.

### ❌ 미참석

- 참가 여부에서 **❌ 미참석**을 누르거나, 날짜 투표 맨 아래 **「❌ 미참석 — 이 중엔 갈 수 있는 날이 없음」**을 누르면 됩니다 (둘은 연동)
- 미참석이면 나머지 항목은 흐리게 표시되고, 눌러도 집계에서 빠집니다. 재촉 명단·여권 확인 대상에서도 빠집니다
- 카톡 요약에 **🙋 갈 사람 / ❌ 미참석** 이름이 같이 나갑니다
- 다시 누르면 언제든 되돌릴 수 있습니다

### 🔒 지난 투표 보존

- 표는 **보기 번호**로 저장됩니다. 보기를 지우거나 순서를 바꿔야 할 땐 투표 정의에 `keys` 배열로 번호를 고정해야
  기존 표가 다른 보기로 옮겨가지 않습니다 (새 보기는 맨 뒤에 붙이고 새 번호를 씀). 코드의 `optKeys()` 주석 참고
- **[💾 지금 저장]은 서버에 없는 것만 채웁니다.** 예전처럼 전체를 덮어쓰지 않으므로, 오래 열어둔 화면에서 눌러도
  그사이 다른 사람이 낸 표가 지워지지 않습니다. 남의 데이터는 건드리지 않고, 지우는 일도 하지 않습니다
- **인터넷이 끊긴 동안 누른 표**는 버리지 않고 브라우저에 보관했다가 연결되면 자동으로 다시 올립니다 (새로고침해도 유지)
- 2026년 10월 쭈꾸미 원정 투표는 **[📜 지난기록]** 탭에 읽기 전용으로 남아 있습니다

## 신년회 교통편 (2026년 10월 확인 기준)

- **퀸비틀(고속선)은 운항 중단** — 2024년 말 선사 사정으로 철수. 부산~하카타 배편은 **뉴카멜리아가 사실상 유일**
- **뉴카멜리아**: 부산 밤 출발 → 익일 아침 하카타, 약 9시간 · 2등실 편도 6~9만원대 (유류세·항만세 1.7~3만원 별도) · 휴항일 있음
- **김해공항 항공**: 약 1시간

요금·시간표는 여행 블로그·예약 대행 사이트 기준이라 자료마다 차이가 있습니다. **예약 전 고려훼리 공식 채널에서 운항일·최종 금액 재확인 필요.**

## 🛂 여권 정보 (신년회용)

[👥 회원] 탭 맨 위 **✏️ 여권 정보 입력** 폼에서 한 사람씩 입력합니다 (폰에서도 세로로 편하게).
홈 화면에 "🛂 여권 정보가 아직 없습니다 → 입력하러 가기"가 뜨면 누르면 바로 폼으로 갑니다.

- 필수는 **영문 성 · 영문 이름 · 만료일** 세 가지. 영문은 자동으로 대문자가 됩니다
- 여권번호를 여기 올리기 싫으면 비워두고 [📋 내 여권정보 복사]로 총무에게 1:1로 보내면 됩니다
- 총무가 대신 넣을 땐 [✏️ 다른 회원 대신 입력]을 켜고 **[다음 미등록자 →]**로 한 명씩 넘기면 됩니다
- 신년회 확정일(미정이면 2027-01-14 가정) 기준으로 **유효기간 6개월 룰**을 자동 판정
  → 🟢 정상 / 🟠 6개월 부족 / 🔴 만료됨 / ⏳ 미등록
- 문제가 있는 사람은 [✈️ 신년회] 탭과 [👥 회원] 탭 상단에 자동으로 표시됩니다
- **다른 사람 여권번호는 기본적으로 가려집니다** (`M12*****`). 예약할 때만 [🔓 여권번호 보기]로 펼칩니다
- [📋 내 여권정보 복사] — 본인 정보를 한 번에 복사해 총무에게 1:1로 보낼 수 있습니다

> ⚠️ **이 페이지와 Firebase 경로는 주소를 아는 사람이면 누구나 볼 수 있습니다.**
> 여권번호를 여기에 올리는 게 꺼림칙하면 영문 성명·만료일만 입력하고, 여권번호는 복사 버튼으로
> 총무에게 1:1 전달하세요. 더 잠그려면 Firebase 익명 인증을 추가해 외부 접근을 막을 수 있습니다.

## 데이터 저장 방식

**Firebase Realtime Database** + 각 회원 브라우저의 `localStorage`.

- 투표·댓글·체크·장비 변경 시 **바뀐 항목만** 즉시 기록 (예: `trip2026/votes/ye_date/홍길동`)
  → 여러 명이 동시에 눌러도 서로 덮어쓰지 않습니다
- 같은 항목을 빠르게 연속 클릭해도 **경로별로 전송을 직렬화**해 마지막 선택이 정확히 저장됩니다
- 다른 회원 화면은 **15초마다 자동 반영** (탭을 다시 열면 즉시 갱신)
- 연결 실패 시 화면에 경고가 뜨고 `localStorage`에만 저장됩니다 (조용히 유실되지 않음)
