# 🦑 서해 워킹 쭈꾸미 원정 2026 — 회원 전용 계획 페이지

2026년 10월 서해 워킹 쭈꾸미 + 차박 원정을 위한 회원 전용 페이지입니다.
날짜·장소·숙박·회비를 **투표**로 정하고, 결과가 모든 회원에게 실시간 공유됩니다.

👉 https://shake777.github.io/tsuri-trip-2026/

## 사용법

1. 위 링크 접속 → 본인 이름 클릭 → 비밀번호 6자리 입력
2. **🗳️ 투표** 탭에서 항목 클릭 (다시 누르면 취소)
3. 끝. 저장 버튼 누를 필요 없이 자동으로 클라우드에 저장됩니다

## 투표 규칙

- **참가 여부만 단일 선택**, 나머지는 전부 **복수 선택**
- 가능한 날짜를 여러 개 고르면 겹치는 날로 자동 집계
- **불참(❌)** 으로 표시한 회원의 표는 집계에서 제외
- 동률이면 "재투표 권장" 안내 표시

## 데이터 저장 방식

- 각 회원 브라우저의 `localStorage` + 이 저장소의 `data.json` 자동 동기화
- 투표·댓글·체크 변경 시 1.5초 뒤 자동으로 `data.json`에 커밋
- 다른 회원이 새로고침하면 즉시 반영
